## Why Java is popular

Java has remained a widely used programming language because of its use across enterprise applications and other development areas. The lesson highlights Java's presence in large organizations and its broad ecosystem.

## JVM and the Java ecosystem

Java uses the **Java Virtual Machine (JVM)** as an execution technology. Other languages such as Kotlin, Scala, and Groovy can also run on the JVM.

A strong understanding of Core Java therefore provides a useful foundation for working with other JVM-based languages.

## Why learn Core Java?

The lesson emphasizes that Java concepts are valuable even when a developer eventually works with another programming language or role. Java also has a strong presence in technical interviews.

## Java: difficult to start, easier to read

Java can feel verbose for beginners, especially compared with languages such as Python or JavaScript. However, the lesson emphasizes Java's readability and maintainability, particularly in larger applications.

## Features previewed

The course will later cover topics including:

## Brief history

- Java was created at **[Sun Microsystems](https://dev.to/poushmita_paul_fddcbe1a2f/java-introduction-what-is-java-who-created-it-and-how-sun-microsystems-became-oracle-4abp#what-was-sun-microsystems)**.
- The original team was led by **James Gosling**.
- Java was introduced in **1995**.
- Oracle later acquired Sun Microsystems and became the owner of the Java trademark.

## Java releases

The lesson explains that modern Java follows a roughly **six-month release cadence**. New releases add features while the core language remains relatively stable.

## Key takeaways

1. Java is important in enterprise software and across many development environments.
2. JVM knowledge is valuable beyond Java itself.
3. Java can be verbose at first but is designed for readable, maintainable code.
4. Core Java provides the foundation for later topics such as OOP, collections, exceptions, and multithreading.
5. Java has evolved continuously since its introduction in 1995.

## One-minute summary

Java is a mature, widely used language with a strong enterprise ecosystem. Its JVM-based execution model also supports other languages. Although Java may feel verbose when starting, its readability and maintainability make it valuable for large applications. The course begins with these foundations and then moves into Core Java programming concepts.
